# Utility Mod — download

Download page for **Utility Mod**, a client-side Fabric utility mod for Minecraft **1.21.11**.

👉 **Download the jar:** [utilitymod-3.3.0.jar](./utilitymod-3.3.0.jar)
(or grab it from the [Releases](../../releases) tab)

Once GitHub Pages finishes building, the download site is at:
**https://sagydori.github.io/minecraft-utility-mod/**

## Install
1. Install **Fabric Loader** for Minecraft 26.1.2.
2. Put **Fabric API** and `utilitymod-3.3.0.jar` in your `.minecraft/mods` folder.
3. Launch the Fabric 26.1.2 profile. Open the in-game menu with **Right Shift**.

## Requirements
- Minecraft 26.1.2 · Fabric Loader 0.16+ · [Fabric API](https://modrinth.com/mod/fabric-api) · Java 25 runtime
