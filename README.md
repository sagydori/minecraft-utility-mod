# Utility Mod — download

Download page for **Utility Mod**, a client-side Fabric utility mod for Minecraft **1.21.11**.

👉 **Download the jar:** [utilitymod-1.0.1.jar](./utilitymod-1.0.1.jar)
(or grab it from the [Releases](../../releases) tab)

Once GitHub Pages finishes building, the download site is at:
**https://sagydori.github.io/minecraft-utility-mod/**

## Install
1. Install **Fabric Loader** for Minecraft 1.21.11.
2. Put **Fabric API** and `utilitymod-1.0.1.jar` in your `.minecraft/mods` folder.
3. Launch the Fabric 1.21.11 profile. Open the in-game menu with **Right Shift**.

## Requirements
- Minecraft 1.21.11 · Fabric Loader 0.16+ · [Fabric API](https://modrinth.com/mod/fabric-api) · Java 21+ runtime
