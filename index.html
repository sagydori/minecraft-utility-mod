Utility Mod

A client-side Fabric utility mod for Minecraft — a humanized action recorder/replayer plus a suite of QoL modules with a custom in-game GUI.

⬇  Download utilitymod-1.0.0.jar
Minecraft 1.21.11 Fabric Loader 0.16+ Java 21+ v1.0.0

Install

  1. Install Fabric Loader for Minecraft 1.21.11.
  2. Put Fabric API and utilitymod-1.0.0.jar in your .minecraft/mods folder.
  3. Launch the Fabric 1.21.11 profile. Open the menu with Right Shift.
