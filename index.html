Features

Everything, in one mod

Each module has its own settings and keybind, saved into switchable profiles.

⏺

Humanized Recorder

Record your movement, camera and actions tick-by-tick, then replay them with natural timing jitter, micro-corrections and reaction delays — never robotic.

🏗

Auto Schematic Builder NEW

Load a schematic and let the mod place it block-by-block with human-like pacing that speeds up and slows down as it goes.

⚙

QoL Modules

AutoSprint, AutoJump, AutoTool, AutoEat, AutoReconnect, Sprint Reset, Rotation Lock, Chat Filter, Anti-AFK, Macros & Fullbright.

🎛

Clean Click GUI

A dark, categorized menu with a search bar, inline settings, sliders, toggles and colour pickers. Opens with Right Shift.

🧭

HUD & Waypoints

Coordinates, FPS/ping/TPS/memory and named waypoints — drag every element where you want it in the HUD editor.

💾

Profiles

Save named config profiles and auto-switch them per server. Every setting persists between sessions.

Get started

Install in three steps

Install Fabric for 26.1.2

Run the Fabric installer and pick Minecraft 26.1.2. This adds a Fabric profile to your launcher.

Add the mods

Drop Fabric API (for 26.1.2) and utilitymod-3.4.0.jar into .minecraft/mods.

Launch & open the menu

Start the Fabric 26.1.2 profile and press Right Shift in-game to open Utility Mod.

A note on Minecraft 26.x

26.x reworked the render pipeline and removed some hooks mods relied on. Block ESP and waypoints currently display as HUD readouts (not 3D outlines), and Freecam is disabled on this version. Everything else — including the recorder and schematic builder — runs normally.
